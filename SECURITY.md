# Security Policy

## Reporting security issues

Please do not open a public GitHub issue for sensitive security reports.

Contact:

- Pietro Melillo
- melillopietro@gmail.com

Include a clear description of the issue, the affected version, the expected behavior, and the observed behavior.

## Sensitive data

Do not attach generated SetupHub reports to public issues unless they have been reviewed and redacted.

Reports may contain:

- computer name;
- username;
- local paths;
- serial numbers;
- network adapters;
- IP addresses;
- MAC addresses;
- installed software inventory.

## Scope

SetupHub relies on WinGet and Microsoft Store sources for package resolution and third-party installers. Issues in third-party installers or vendor packages should also be reported to the relevant vendor.
