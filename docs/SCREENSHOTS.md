# Screenshot Guide

Screenshots make the repository easier to understand, but they can also leak workstation data. Use clean screenshots and review them before publishing.

## Recommended screenshots

Save these files under `assets/screenshots/`:

```text
setuphub-main.png
setuphub-profile.png
setuphub-report.png
setuphub-inventory.png
setuphub-credits.png
```

## What to capture

1. Main SetupHub window with a standard profile selected.
2. Custom profile creation using the New profile button.
3. Software catalog after validation.
4. Final HTML report summary.
5. Credits/license window.

## What to remove or blur

- Computer name
- Username if not intended for publication
- Serial numbers
- MAC addresses
- IP addresses
- Local paths
- Private software inventory
- Internal hostnames

## Recommended format

- PNG format
- 1200-1600 px width
- Dark theme if possible
- No unnecessary desktop background
- No unrelated browser tabs or files in view
