# Contributing

Contributions are welcome when they keep SetupHub simple, auditable, and useful for real Windows workstation preparation.

## Guidelines

- Keep package IDs explicit and validated.
- Do not add random installer URLs directly to the script.
- Prefer WinGet or Microsoft Store package sources.
- Keep generated reports out of commits.
- Do not commit private inventory files, logs, screenshots with serial numbers, or machine-specific data.
- Update the changelog for meaningful changes.
- Keep the interface bilingual when adding visible text.
